# SHERBET 설치 도우미

정렬 리쉐이드 구매자 전용 도구입니다. 디스코드 구매자 역할이 있어야 진행됩니다.

리쉐이드 설치와 파이브엠 설정을 한 번에 맞춰 줍니다.

- 받기: [SherbetSetup.exe](https://github.com/Jeong-Ryeol/sherbet-setup/releases/latest/download/SherbetSetup.exe)
- 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러 주세요.
- 켤 때마다 스스로 최신 버전을 확인합니다.

사용 방법 영상은 디스코드 #홍보영상 채널에 있습니다.
